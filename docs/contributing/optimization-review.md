# Toolchain optimization review

Scope: unreleased source after 0.4.0. Existing public exports, dependencies, language output and correctness/coverage/size gates remain intact. Measurements and limits are in [benchmark history](../benchmark-history.md#unreleased-toolchain-optimization).

| Package/surface | Review outcome                                                                                                                                                                                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Compiler        | Deduplicate conditional Acorn entries in the bundled CJS bridge; retain ESM dependency resolution and maps. Defer CLI backends after help/argument validation. No parser/lowering/checker algorithm change.                                                      |
| VS Code         | Reuse host TypeScript; load the bundled formatter on demand, retain native module caching, cancellation/version checks and preview fallback. Keep one complete editor notice and every chunk. Validate actual minimum/stable hosts and original-source coverage. |
| Formatter       | Keep Prettier/native TS parsing and the source-preserving dialect parser. Production files/archive remain identical; skipping either parse would risk syntax/layout fidelity.                                                                                    |
| Linter          | Build native and LF-only line starts in one regex scan. Preserve every newline/UTF-16 mapping, fix/suggestion safety, typed project refresh and cache limits.                                                                                                    |
| Export          | Delay backend imports after help/argument checks. Keep checked source traversal, canonical path/collision preflight, asset copying and exclusive destination ownership. The small archive increase is intentional.                                               |
| Highlight       | Keep engine-free grammar exports, optional Shiki 2/3/4 support, browser WASM and reusable highlighters. Production files/archive remain identical.                                                                                                               |
| Runtime         | Keep the zero-dependency helpers/v1 ABI, cleanup order, exception identities and suspension semantics. Its 3.3 KB archive is unchanged.                                                                                                                          |
| Shell           | Keep zero production dependencies, snapshots, byte bounds, cancellation/timeout races, pipe lifetime and teardown contracts. No process-lifecycle rewrite; runtime files and metadata values remain identical.                                                   |
| Documentation   | Share parser deduplication with the compiler worker. Keep desktop/mobile root/subpath guidance, canonical skill downloads and source-versus-published labels.                                                                                                    |

Validation covers seven public archives independently installed on Node 20.19, all owning source-coverage gates, actual minimum/stable VSIX hosts, unchanged language-output behavior/byte checks, examples/React-Vue rendering, type/lint/format checks and root/subpath browsers. Supported non-Linux process contracts remain in the existing full PR CI; no new performance benchmark is added to required CI.
